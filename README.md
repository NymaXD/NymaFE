**NymaFE** es un lenguaje de dominio específico (DSL) diseñado para manipular archivos y directorios del sistema operativo mediante comandos simples y fáciles de memorizar. Nació como proyecto para una hackathon con el objetivo de reducir la fricción de las tareas cotidianas de gestión de archivos, ofreciendo una sintaxis clara y consistente.

*NymaFE is a domain-specific language (DSL) designed to manipulate files and directories in the operating system through simple, easy-to-memorize commands. It was born as a hackathon project with the goal of reducing the friction of everyday file management tasks by offering a clear and consistent syntax.*

## Descripción

Con NymaFE puedes operar sobre archivos 📄 y carpetas 📁 dentro de un directorio: leer su contenido, abrirlos, renombrarlos, copiarlos, moverlos y más. El lenguaje está pensado para que la sintaxis sea legible tanto para personas que se inician en la programación como para quienes buscan una forma más directa de interactuar con el sistema de archivos.

*With NymaFE you can operate on files 📄 and folders 📁 within a directory: read their contents, open them, rename them, copy them, move them, and more. The language is designed so its syntax is readable both for people starting out in programming and for those looking for a more direct way to interact with the file system.*

## Características

- Sintaxis simple y orientada a comandos.
- Operaciones básicas sobre archivos y directorios.
- Documentación completa en la wiki del proyecto.
